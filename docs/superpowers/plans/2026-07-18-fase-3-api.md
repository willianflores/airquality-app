# Fase 3 — API Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** API REST pública de leitura (readings/metrics/municípios), hardening do `PurpleAirClient` contra desperdício de pontos, e autenticação admin (login/sessão/seed).

**Architecture:** Hexagonal, seguindo o padrão já estabelecido (port + adapter Postgres + use case + router FastAPI). Endpoints de leitura consomem continuous aggregates (nunca `sensor_readings` bruto). Auth usa cookie httpOnly + sessão em Postgres, sem Redis.

**Tech Stack:** FastAPI, SQLAlchemy, `argon2-cffi` (novo), stdlib `hashlib`/`secrets` — sem outras dependências novas.

## Global Constraints

- Spec: `docs/superpowers/specs/2026-07-18-fase-3-api-design.md`
- Endpoints de leitura nunca consultam `sensor_readings` bruto — sempre `municipio_hourly_pm25`, `who_exceedance_days` (que já inclui `pm2_5_avg` + `exceeds_who_threshold` juntos, é a fonte pra `granularity=daily`).
- `/readings/history`: `start`/`end` obrigatórios, limite máximo de intervalo 90 dias (`hourly`) / 2 anos (`daily`) — excedido retorna `422`.
- `/metrics/month-hour-matrix` e `/metrics/municipio-year-exceedance`: calculados ao vivo a cada request (sem tabela nova, sem job agendado — testado ~0.1s mesmo sobre centenas de milhares de linhas).
- `PurpleAirClient.fetch_history` muda de `-> list[dict]` pra `-> Iterator[list[dict]]` (um `yield` por janela de 30 dias) — quebra de contrato deliberada pra não perder dado já baixado/pago se uma janela no meio falhar. `BackfillHistoricalPurpleAir` persiste (`bulk_insert`) a cada janela recebida, não uma vez por sensor.
- Retry em `_request_with_retry` só repete pra `httpx.HTTPStatusError` com `status_code >= 500`, ou `httpx.TransportError`/`httpx.TimeoutException`. Erro 4xx propaga na primeira tentativa (sem retry).
- `admin_sessions` ganha coluna `token_hash` (migration `0007`) — cookie carrega token bruto (`secrets.token_urlsafe(32)`), banco guarda só `sha256(token)`.
- Senha: `argon2-cffi`, hash argon2id.
- Sessão: cookie `httpOnly` + `Secure` + `SameSite=Strict`, 8h, renovada (sliding) a cada validação bem-sucedida.
- Rate limit login: em memória, 5 tentativas falhas / 15min por IP, sem Redis.
- Sem rota pública de signup — admin criado via CLI (`infrastructure/create_admin.py`).
- CSRF header customizado fica fora do escopo desta fase (não há rota de mutação admin ainda — isso é Fase 5).

```python
from datetime import datetime

from sqlalchemy import text
from sqlalchemy.orm import Session

from application.ports.reading_repository import ReadingRepository
from domain.entities.municipio_daily_reading import MunicipioDailyReading
from domain.entities.municipio_reading import MunicipioReading


class PostgresReadingRepository(ReadingRepository):
    def __init__(self, session: Session) -> None:
        self._session = session

    def current(self) -> list[MunicipioReading]:
        rows = self._session.execute(
            text("""
                SELECT DISTINCT ON (municipio) municipio, bucket, pm2_5_avg
                FROM municipio_hourly_pm25
                ORDER BY municipio, bucket DESC
            """)
        ).all()
        return [
            MunicipioReading(municipio=r.municipio, bucket=r.bucket, pm2_5_avg=r.pm2_5_avg)
            for r in rows
        ]

    def history_hourly(
        self, start: datetime, end: datetime, municipio: str | None
    ) -> list[MunicipioReading]:
        stmt = text("""
            SELECT municipio, bucket, pm2_5_avg
            FROM municipio_hourly_pm25
            WHERE bucket >= :start AND bucket < :end
              AND (:municipio IS NULL OR municipio = :municipio)
            ORDER BY bucket
        """)
        rows = self._session.execute(
            stmt, {"start": start, "end": end, "municipio": municipio}
        ).all()
        return [
            MunicipioReading(municipio=r.municipio, bucket=r.bucket, pm2_5_avg=r.pm2_5_avg)
            for r in rows
        ]

    def history_daily(
        self, start: datetime, end: datetime, municipio: str | None
    ) -> list[MunicipioDailyReading]:
        stmt = text("""
            SELECT municipio, bucket, pm2_5_avg, exceeds_who_threshold
            FROM who_exceedance_days
            WHERE bucket >= :start AND bucket < :end
              AND (:municipio IS NULL OR municipio = :municipio)
            ORDER BY bucket
        """)
        rows = self._session.execute(
            stmt, {"start": start, "end": end, "municipio": municipio}
        ).all()
        return [
            MunicipioDailyReading(
                municipio=r.municipio,
                bucket=r.bucket,
                pm2_5_avg=r.pm2_5_avg,
                exceeds_who_threshold=r.exceeds_who_threshold,
            )
            for r in rows
        ]
```

```python
from datetime import datetime, timedelta

from application.ports.reading_repository import ReadingRepository

MAX_RANGE_HOURLY = timedelta(days=90)
MAX_RANGE_DAILY = timedelta(days=730)


class InvalidRangeError(Exception):
    pass


class GetHistoricalReadings:
    def __init__(self, reading_repository: ReadingRepository) -> None:
        self._reading_repository = reading_repository

    def execute(self, start: datetime, end: datetime, granularity: str, municipio: str | None):
        max_range = MAX_RANGE_DAILY if granularity == "daily" else MAX_RANGE_HOURLY
        if end - start > max_range:
            raise InvalidRangeError(
                f"Intervalo máximo para granularity={granularity} é {max_range.days} dias"
            )
        if granularity == "daily":
            return self._reading_repository.history_daily(start, end, municipio)
        return self._reading_repository.history_hourly(start, end, municipio)
```

```python
from datetime import datetime, timedelta, timezone

from fastapi import APIRouter, Depends, HTTPException, Query
from sqlalchemy.orm import Session

from adapters.outbound.postgres.postgres_reading_repository import PostgresReadingRepository
from application.use_cases.get_current_readings import GetCurrentReadings
from application.use_cases.get_historical_readings import GetHistoricalReadings, InvalidRangeError
from infrastructure.dependencies import get_db_session

router = APIRouter(prefix="/readings")


def get_current_readings_use_case(session: Session = Depends(get_db_session)) -> GetCurrentReadings:
    return GetCurrentReadings(PostgresReadingRepository(session))


def get_historical_readings_use_case(session: Session = Depends(get_db_session)) -> GetHistoricalReadings:
    return GetHistoricalReadings(PostgresReadingRepository(session))


@router.get("/current")
def get_current(use_case: GetCurrentReadings = Depends(get_current_readings_use_case)) -> list[dict]:
    readings = use_case.execute()
    return [{"municipio": r.municipio, "bucket": r.bucket, "pm2_5_avg": r.pm2_5_avg} for r in readings]


@router.get("/history")
def get_history(
    start: str = Query(...),
    end: str = Query(...),
    granularity: str = Query("hourly", pattern="^(hourly|daily)$"),
    municipio: str | None = Query(None),
    use_case: GetHistoricalReadings = Depends(get_historical_readings_use_case),
) -> list[dict]:
    start_dt = datetime.strptime(start, "%Y-%m-%d").replace(tzinfo=timezone.utc)
    end_dt = datetime.strptime(end, "%Y-%m-%d").replace(tzinfo=timezone.utc) + timedelta(days=1)
    try:
        readings = use_case.execute(start_dt, end_dt, granularity, municipio)
    except InvalidRangeError as error:
        raise HTTPException(status_code=422, detail=str(error))

    if granularity == "daily":
        return [
            {
                "municipio": r.municipio,
                "bucket": r.bucket,
                "pm2_5_avg": r.pm2_5_avg,
                "exceeds_who_threshold": r.exceeds_who_threshold,
            }
            for r in readings
        ]
    return [{"municipio": r.municipio, "bucket": r.bucket, "pm2_5_avg": r.pm2_5_avg} for r in readings]
```

```python
from sqlalchemy import text
from sqlalchemy.orm import Session

from application.ports.metrics_repository import MetricsRepository
from domain.entities.month_hour_cell import MonthHourCell
from domain.entities.municipio_year_exceedance import MunicipioYearExceedance


class PostgresMetricsRepository(MetricsRepository):
    def __init__(self, session: Session) -> None:
        self._session = session

    def month_hour_matrix(self) -> list[MonthHourCell]:
        rows = self._session.execute(
            text("""
                SELECT EXTRACT(MONTH FROM bucket)::int AS mes,
                       EXTRACT(HOUR FROM bucket)::int AS hora,
                       COUNT(*) AS total
                FROM municipio_hourly_pm25
                WHERE pm2_5_avg > 15
                GROUP BY mes, hora
            """)
        ).all()
        totals = {(r.mes, r.hora): r.total for r in rows}
        return [
            MonthHourCell(mes=mes, hora=hora, total=totals.get((mes, hora), 0))
            for mes in range(1, 13)
            for hora in range(24)
        ]

    def municipio_year_exceedance(self) -> list[MunicipioYearExceedance]:
        rows = self._session.execute(
            text("""
                SELECT municipio, EXTRACT(YEAR FROM bucket)::int AS ano,
                       COUNT(*) FILTER (WHERE exceeds_who_threshold) AS dias_acima_oms
                FROM who_exceedance_days
                GROUP BY municipio, ano
                ORDER BY municipio, ano
            """)
        ).all()
        return [
            MunicipioYearExceedance(municipio=r.municipio, ano=r.ano, dias_acima_oms=r.dias_acima_oms)
            for r in rows
        ]
```

```python
    def __init__(
        self,
        sensor_repository: SensorRepository,
        purpleair_client: PurpleAirClient,
        sensor_reading_repository: SensorReadingRepository,
        ingestion_run_repository: IngestionRunRepository,

        self._purpleair_client = purpleair_client
```

```python
import hashlib
import secrets
from datetime import datetime, timedelta, timezone

from application.ports.admin_session_repository import AdminSessionRepository
from application.ports.admin_user_repository import AdminUserRepository
from application.ports.password_hasher import PasswordHasher

SESSION_DURATION = timedelta(hours=8)


class InvalidCredentialsError(Exception):
    pass


def hash_token(token: str) -> str:
    return hashlib.sha256(token.encode()).hexdigest()


class Login:
    def __init__(
        self,
        admin_user_repository: AdminUserRepository,
        admin_session_repository: AdminSessionRepository,
        password_hasher: PasswordHasher,
    ) -> None:
        self._admin_user_repository = admin_user_repository
        self._admin_session_repository = admin_session_repository
        self._password_hasher = password_hasher

    def execute(self, email: str, password: str) -> tuple[str, str]:
        admin = self._admin_user_repository.find_by_email(email)
        if admin is None or not self._password_hasher.verify(password, admin.password_hash):
            raise InvalidCredentialsError

        token = secrets.token_urlsafe(32)
        expires_at = datetime.now(timezone.utc) + SESSION_DURATION
        self._admin_session_repository.create(admin.id, hash_token(token), expires_at)
        self._admin_user_repository.touch_last_login(admin.id)
        return token, admin.email
```

```python
from datetime import datetime, timedelta, timezone

MAX_ATTEMPTS = 5
WINDOW = timedelta(minutes=15)


class InMemoryLoginRateLimiter:
    def __init__(self) -> None:
        self._attempts: dict[str, list[datetime]] = {}

    def is_blocked(self, ip: str) -> bool:
        self._prune(ip)
        return len(self._attempts.get(ip, [])) >= MAX_ATTEMPTS

    def record_failure(self, ip: str) -> None:
        self._prune(ip)
        self._attempts.setdefault(ip, []).append(datetime.now(timezone.utc))

    def _prune(self, ip: str) -> None:
        cutoff = datetime.now(timezone.utc) - WINDOW
        if ip in self._attempts:
            self._attempts[ip] = [t for t in self._attempts[ip] if t > cutoff]
```

```python
from datetime import datetime, timezone

from fastapi import APIRouter, Depends, HTTPException, Request, Response
from pydantic import BaseModel
from sqlalchemy.orm import Session

from adapters.outbound.memory.in_memory_login_rate_limiter import InMemoryLoginRateLimiter
from adapters.outbound.postgres.postgres_admin_session_repository import PostgresAdminSessionRepository
from adapters.outbound.postgres.postgres_admin_user_repository import PostgresAdminUserRepository
from adapters.outbound.security.argon2_password_hasher import Argon2idPasswordHasher
from application.use_cases.login import InvalidCredentialsError, Login, SESSION_DURATION, hash_token
from infrastructure.dependencies import get_db_session

router = APIRouter(prefix="/auth")

COOKIE_NAME = "admin_session"

_rate_limiter = InMemoryLoginRateLimiter()


class LoginRequest(BaseModel):
    email: str
    password: str


def get_login_use_case(session: Session = Depends(get_db_session)) -> Login:
    return Login(
        PostgresAdminUserRepository(session),
        PostgresAdminSessionRepository(session),
        Argon2idPasswordHasher(),
    )


@router.post("/login")
def login(
    body: LoginRequest,
    request: Request,
    response: Response,
    use_case: Login = Depends(get_login_use_case),
) -> dict:
    client_ip = request.client.host if request.client else "unknown"
    if _rate_limiter.is_blocked(client_ip):
        raise HTTPException(status_code=429, detail="Muitas tentativas. Tente novamente mais tarde.")

    try:
        token, email = use_case.execute(body.email, body.password)
    except InvalidCredentialsError:
        _rate_limiter.record_failure(client_ip)
        raise HTTPException(status_code=401, detail="Credenciais inválidas")

    response.set_cookie(
        key=COOKIE_NAME,
        value=token,
        httponly=True,
        secure=True,
        samesite="strict",
        max_age=int(SESSION_DURATION.total_seconds()),
    )
    return {"email": email}


def get_current_admin(request: Request, session: Session = Depends(get_db_session)) -> str:
    token = request.cookies.get(COOKIE_NAME)
    if token is None:
        raise HTTPException(status_code=401, detail="Não autenticado")

    session_repository = PostgresAdminSessionRepository(session)
    admin_session = session_repository.find_by_token_hash(hash_token(token))
    if admin_session is None or admin_session.expires_at < datetime.now(timezone.utc):
        raise HTTPException(status_code=401, detail="Sessão inválida ou expirada")

    session_repository.extend_expiry(
        admin_session.id, datetime.now(timezone.utc) + SESSION_DURATION
    )

    admin_user_repository = PostgresAdminUserRepository(session)
    admin = admin_user_repository.find_by_id(admin_session.admin_id)
    return admin.email


@router.get("/me")
def me(email: str = Depends(get_current_admin)) -> dict:
    return {"email": email}


@router.post("/logout")
def logout(request: Request, response: Response, session: Session = Depends(get_db_session)) -> dict:
    token = request.cookies.get(COOKIE_NAME)
    if token is not None:
        PostgresAdminSessionRepository(session).delete(hash_token(token))
    response.delete_cookie(COOKIE_NAME)
    return {"status": "ok"}
```
